## Sustainability and Learning
Why use cheatsheets over not web search or AI?

> "_Memory is the residue of thought_." (Daniel T. Willingham)

Your brain is kind of like a [cache](https://en.wikipedia.org/wiki/Cache_(computing)) for the things you've learned about or looked up. Unfortunately, if you never access those memories, you always need to go to the slower lookup method anyway (even if you've done so before). This looks like asking ChatGPT the same question week after week; you've never really needed to remember it because you know Chat's always there.

Maybe this is fine as long as ChatGPT never goes down... but it's really wasteful. Cheatsheets (and documentation) are a much higher quality **and** more efficient as [cache](https://en.wikipedia.org/wiki/Cache_(computing)) than AI and web search.
## Resourcefulness
Did you ever hear of students making a [bridge out of spaghetti](https://en.wikipedia.org/wiki/Spaghetti_bridge)? This project is not done because real bridges are made out of spaghetti; it is done because it teaches students to work effectively with constrained resources.

Working with cheatsheets over resources like web search or AI chatbots will teach you to be resourceful, which is an invaluable skill.

## Caveats
To be clear, cheatsheets are not always the best way to get the answer to a question or do so quickly. Sometimes AI or web search is better!
